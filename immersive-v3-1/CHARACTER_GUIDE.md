# 鹈鹕角色与动作规范

适用：沉浸版主场景、场景预览和旅行照片。更新日期：2026-09-16。
当前休息姿态为背身坐在长凳上，捧着咖啡看风景；骑行造型保持不变。

## 身份保持一致

| 识别特征 | 共用约束 | 随动作允许变化 |
| --- | --- | --- |
| 头部与面部 | 正侧面沿用 `pelican-head-profile`、`pelican-face-features`；背面使用 `pelican-back-head`，保持喙、喉囊、头盔配色与结构特征 | 头部旋转、透视缩短；背面不绘制正面眼睛 |
| 羽毛 | 延续暖白羽毛、低饱和阴影、原有描边体系 | 光照、躯干压缩、颈部收放 |
| 围巾 | 领口保持同一角色配色和位置逻辑 | 骑行时飘起；坐下时垂落 |
| 翅膀 | 保持羽毛结构和连接逻辑 | 握车把、折叠、承托咖啡杯 |
| 腿与脚 | 保持腿脚颜色、比例和关节连接 | 踩踏、弯曲下垂、承重站立 |

一致性不要求复用整只骑行角色的姿态。先保持身份，再表达动作需要的重心、轮廓和遮挡。
共享资产在 `index.html` 的 `COMPONENTS.defs` / `COMPONENTS.rider` 中维护；主场景与照片通过各自 ID 前缀复用，不能产生重复引用。

## 当前姿态

| 姿态 | 使用场景 | 必须表达的关系 |
| --- | --- | --- |
| 骑行 | 主场景旅行、专注期间、骑行照片 | 脚与踏板相连，翅膀与车把相连，身体有骑行重心；轮子、踏板和腿的运动协调 |
| 坐着休息 | 休息、完成后停靠、休息照片 | 背朝观众，头朝向远景；右翅托杯、左翅折叠，围巾垂在背侧；近侧靠背遮住下背，脚垂在凳子远侧 |
| 看风景 | 旅行照片第三种取景 | 保持同一头盔、喙、围巾和羽毛；站姿有明确承重脚，不混用坐姿腿 |

主场景和照片的坐姿必须都使用 `COMPONENTS.rest`，不另建相似但不同的角色副本。

## 坐姿约束

- `rest-body` 腹部下沿与座面接触，`rest-contact-shadow` 位于接触处，不能表现为悬浮。
- `rest-seated-legs` 位于远侧，腿根被座面和下背遮住；短而自然下垂，不与凳腿混成同一轮廓。
- `rest-folded-wing` 折在左身侧；`rest-coffee-wing` 连接右肩，`rest-cup-grip` 托住杯底，不让杯子悬空或出现人类手指。
- `rest-head` 使用背面头部，露出后脑盔壳、后扣和透视缩短的喙；不露正面眼睛，不将侧面头部直接水平翻转冒充背影。
- `rest-bench` 在角色之后绘制，近侧靠背遮住下背，明确角色面朝风景；不能把角色画在靠背前方。
- 咖啡杯随承托翅膀保持连接，杯口朝上；小桌只留杯碟。蒸汽使用静态轻线条，不新增循环动画。
- 呼吸只影响上身，以腹部下沿为支点；凳子、腿、脚和接触阴影保持稳定。
- 凳子、自行车和桌子的比例保持当前基准，不通过整体压扁角色制造坐姿。

## 状态与动作

暂停的是专注计时，不是独立旅行，因此不能仅因“暂停”将鹈鹕改成睡觉或停止整个世界。
专注结束和休息使用坐姿；旅行先到期但专注未结束时，保持当前专注画面，避免打断。
场景预览、照片不更改实际计时、声音或旅行进度。

当前继续使用已有轻微动画和切换方式。本轮不新增下车、坐下、起身的连续动画。
后续如果新增这些过渡，必须先确认分镜与接触锚点，再修改实现；禁止直接用两张不相关轮廓拉伸变形。
“静止画面”和系统“减少动态效果”下，不新增呼吸、摆动、位移过渡。

## 视觉回归清单

1. 桌面、375 px 手机、844 × 390 横屏：喙和脚不被裁掉，提示和胶囊不覆盖角色关键部位。
2. 白天和重庆夜景：共享资产无缺失，角色没有因 UI 配色改变而变色。
3. 主场景与旅行册：同种姿态复用同一组件；头部识别特征一致。
4. 全部 SVG 的 `use` 和 `url(#...)` 指向当前 SVG 内有效资产，无重复 ID。
5. 休息呼吸前后：凳面接触位置不漂移；静止和减少动态效果下无呼吸。
6. 明信片导出继续保持既有画幅、角色比例和资产引用，不把首页提示导入照片。
7. 背影无正面眼睛；手机宽度下能分辨头盔、围巾、托杯动作；主场景和休息照片均使用同一背影。

自动检查通过只能证明引用和状态未破坏。造型自然度、动作语义仍需要查看实际渲染截图。
