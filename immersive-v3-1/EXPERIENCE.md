# 旅行鹈鹕：体验与状态规则

本文件是沉浸版的产品行为约定。更新日期：2026-09-16。
适用入口：`/immersive-v3-1/`。根目录沿途电台版和 `minimal/` 保持独立，不随本轮更新改变。

## 产品边界

为工作、阅读和短暂休息提供低干扰陪伴。用户可以选择专注计时，也可以自由陪伴、不计时。
旅行进度独立于专注计时；照片是旅途纪念，不是实际专注程度的证明。
本阶段不增加账号、云同步、连续签到、排行榜、惩罚机制和限时领取。

## 两条独立的时间线

| 操作或状态 | 专注计时与记录 | 当前旅行与收藏 | 角色与声音 |
| --- | --- | --- | --- |
| 首次进入 | 默认等待用户开始 25 分钟专注 | 准备第一段 15 分钟旅行 | 骑行；声音等待用户主动操作 |
| 首次选择自由陪伴 | 不启动计时，不生成专注记录；偏好改为不计时 | 继续当前旅行 | 尝试开启声音，尊重已有静音偏好 |
| 开始专注 | 开始计时，首轮沿用已准备的地点 | 继续当前旅行 | 骑行；尝试开启声音 |
| 暂停／继续专注 | 暂停／继续同一轮，不重新选地点 | 旅行继续 | 不因暂停计时强制切姿态或静音；显示“专注已暂停” |
| 专注完成 | 本轮只记录一次；用户决定休息或下一轮 | 旅行继续，不因完成专注赠送照片 | 坐下休息；允许时轻响，降低声音强度 |
| 提前结束 | 记录已计时部分，标记为未完成 | 旅行继续 | 停靠休息，不伪装成完成整轮 |
| 开始／暂停休息 | 使用休息时长，不计入专注统计 | 旅行继续 | 坐姿；显示“休息中／休息已暂停” |
| 显式开始下一轮 | 开始新一轮 | 随机模式选另一处已开放地点；固定模式保留选择 | 使用新活动地点；声音不重启整首配乐 |
| 切换未完成旅行 | 不干扰正在进行的专注／休息；受保护时不立即切换 | 保存旧地点的剩余时间和照片结果；仅活动地点推进 | 预览不改变主场景、计时和声音 |
| 旅行到期 | 不结束或切换当前专注 | 收录一张照片；首次到访收录纪念章；同一旅程不重复结算 | 专注时保持骑行，不弹奖励；没有专注保护时停靠 |
| 切换工作窗口 | 继续按结束时间计算 | 旅行继续 | 隐藏时停止画面刷新；声音尽可能继续 |
| 刷新／离开页面 | 保存为暂停快照；回来需主动继续；不补算离线专注时间 | 回来最多结算离开前的当前一段，不模拟连续离线旅行 | 不自动强制出声 |
| 手机锁屏／浏览器冻结 | 回来核对剩余时间；不能保证冻结期间准时提醒 | 回来核对当前旅行是否到期 | 声音可能中断；提供恢复入口 |
| 静音／静止画面 | 不改变计时 | 不改变旅行或收藏资格 | 分别控制声音和动画 |

刷新后的暂停时间以成功保存的快照为准；异常关闭可能回退到最近一次定期保存。
不同地点暂存的旅行不会同时在后台计时。切景本身不增加完成次数。
新用户在累计完成第 1／3／6 段旅行后开放新地点；六处地点共 18 种照片，重复照片合并次数、不覆盖首次日期。

## 首次使用与重访

- 新存档显示可收起的非模态提示，不抢键盘焦点，不锁住主场景。
- 可以选择专注、自由陪伴，或直接收起；Escape 也可收起。
- 已有计时、偏好或旅行数据的用户不自动展示提示。
- 设置 → 偏好 → 怎样使用旅行鹈鹕，可重新查看提示。
- 重新查看时，当前专注或休息不被替换；进行中的一轮隐藏模式选择。
- 自由陪伴可通过设置中的“专注时长”改回计时，不额外添加常驻首页按钮。

## 状态反馈

计时胶囊显示“专注中／休息中／已暂停”；数字可隐藏，状态仍可辨认。
状态文字只在内容变化时更新，避免每秒向屏幕阅读器重复播报。

| 声音状态 | 用户看到的反馈 | 可用处理 |
| --- | --- | --- |
| 尚未主动开启 | 偏好内说明等待主动操作 | 开始专注或点击声音 |
| 正在准备 | 简短准备提示，计时仍可操作 | 等待或收起提示 |
| 正常播放 | 操作后短暂提示，然后自动收起 | 静音 |
| 用户静音 | “已静音”，保留原偏好 | 再次主动开启 |
| 音量为零 | “音量为 0” | 直接进入音量设置 |
| 浏览器暂停／环境声失败 | “声音待恢复”或环境声待恢复 | 点击重试，不重置计时 |
| 配乐失败，环境声仍在 | 分别说明可用与失败部分 | 重试配乐或选择本地音乐 |

恢复提示可收起；同一状态不会反复弹出。声音问题不触发旅行奖励或权限弹窗。
到时提醒是尽力提供的网页能力，不承诺在系统休眠、锁屏或浏览器冻结期间必达。

## 验收与待验证

自动检查入口：`node tests/immersive-experience.cjs`（在仓库根目录运行）。
覆盖新存档、旧存档、引导跳过与重开、专注暂停与休息、静音恢复、旅行独立结算、刷新恢复、响应式布局和共享角色引用。
测试使用独立浏览器配置和临时本地网址，不读取或清除日常浏览器的用户数据。

浏览器模拟不代替真实手机锁屏、耗电、声音听感和屏幕阅读器验收。发布前记录本次实际执行范围。
下一阶段可邀请 3–5 位首次使用者完成“开始、暂停、休息、查看收藏”，观察是否理解两条时间线；尚无这类用户测试结论。
